# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

omega is personal and single-user first. Its user works across a Mac and WhatsApp, wants
to delegate without repeated briefing, and expects an assistant to remember ongoing work
and relevant patterns without being manually maintained like a reminder app.

## Product Purpose

omega is a second brain that behaves like a person rather than a chat tool. It supports
delegation and thinking, maintains continuity, takes useful initiative, forms reasoned
opinions, and learns how its user works. Success means delegated work produces an honest,
verified state change and can continue across surfaces without re-briefing.

## Positioning

omega is not a generic chat interface, a transcript archive, or a dashboard over tools.
Its distinguishing mechanism is a persistent working relationship: open work remains in
working memory, relevant history returns associatively, and useful observations can be
surfaced without an explicit reminder.

## Operating Context

The v1 desk surface lives at the top-center of macOS, visually attached to the camera
housing where one exists. It can stay visible while the user works in other applications,
accept screen and file context, and show responses or proactive messages without stealing
focus. WhatsApp is the planned pocket surface.

## Capabilities and Constraints

- v1 includes basic identity, continuity, initiative, opinions, and knowing-the-user.
- Reliability and cross-channel reach are quality bars, not optional features.
- Mac capture is explicit and staged before submission; capture never silently means send.
- The Mac surface remains a channel and does not own agent memory or judgement.
- A full Mac application, history browser, memory UI, advanced workflows, and realtime
  voice are deferred beyond the tray v1.
- omega is built from scratch. No Hermes code or architecture is used unless explicitly
  requested later.

## Brand Commitments

The name is omega. It should feel like a quiet, capable presence rather than branded AI
software. Its interface is restrained, direct, and recognizably consistent under normal
work, errors, long tasks, and disagreement.

## Evidence on Hand

There is no existing visual implementation or production agent contract. The confirmed
Mac tray behavior and visual system are documented in
`apps/mac-tray/docs/V1_SPEC.md`. Product-wide decisions live privately in `AGENT.md`.

## Product Principles

- Apply the human test: build how a capable person would handle the situation.
- Stay small and legible; every layer and feature must earn its place.
- Done means a verified state change, reported honestly.
- Preserve user agency: visible context, explicit sending, recoverable actions.
- Channel is transport, never scope; omega remains the same person everywhere.

## Accessibility & Inclusion

The Mac surface must support keyboard-only use, VoiceOver, increased contrast, reduced
motion, reduced transparency, differentiation without color, and light/dark system
conditions. State may never be communicated through color alone.
